# Scrapbook Ulang Tahun

Scrapbook ulang tahun interaktif berbasis Next.js yang berisi kolase foto, video kenangan, surat, dan musik.

## Menjalankan secara lokal

```bash
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.

## Memeriksa build produksi

```bash
npm run lint
npm run build
```

Video dan musik menunggu interaksi pengguna, gambar dekorasi di bawah layar dimuat secara lazy, dan font di-host bersama aplikasi agar halaman tetap ringan di perangkat seluler.

## Deploy

Proyek dapat dideploy ke Vercel menggunakan konfigurasi Next.js bawaan.
